# Figures

Figures for the weekly Substack posts, published by write_post.py; one folder per report date.

Written by `vv-paper-fetcher/src/substack_post/figure_host.py`. Each file is served from
`https://raw.githubusercontent.com/<owner>/<repo>/figures/<YYYY-MM-DD>/<file>`, and the
posts link to those URLs, so don't move, rename or delete files once a post is out.
